# Group-Project-IST-256_Group-9

Student club website for the Web Dev Club.

# Project Features

- Homepage with information about the club
- Navigation between pages
- Member sign-up page
- Form validation using JavaScript
- User information stored in JSON format

# Files

- index.html - Main homepage
- signup.html - Member sign-up page
- style.css - Website styling
- script.js - JavaScript + form validation
- users.json - User + member data
